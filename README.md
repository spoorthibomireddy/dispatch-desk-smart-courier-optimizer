# 🚚 Dispatch Desk – Smart Courier Optimizer

A smart courier package selection and delivery optimization system built with Streamlit.

## 🎯 Problem Statement

Courier vehicles have limited capacity, while multiple packages may need to be delivered. Selecting packages manually can waste vehicle capacity, reduce delivery value, and cause urgent packages to be missed.

## 💡 Solution

Dispatch Desk helps select the most suitable packages for delivery based on vehicle capacity and package information. It provides an easy-to-use dashboard for making smarter delivery decisions.

## ✨ Key Features

- 📦 Package management
- 🚚 Vehicle capacity management
- ⚡ Smart package selection
- 💰 Maximizes delivery value
- 🚨 Handles package priority
- 📊 Displays optimization results
- 🎨 Interactive Streamlit interface
- 📈 Easy-to-understand results

## 🧠 Optimization

The system considers package weight, value, priority, and available vehicle capacity to determine a suitable package selection.

## 🛠️ Technologies Used

- Python
- Streamlit
- Data Structures & Algorithms
- Optimization / Knapsack-based approach
